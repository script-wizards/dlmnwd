# Third-party assets

`LICENSE` (MIT) covers this repository's own code, styles, and copy. It does not
cover the vendored fonts below, which keep their own terms, and it does not
cover Dolmenwood, which is © Necrotic Gnome and is not distributed here.

## web/fonts/DepartureMono-Regular.woff2

Departure Mono, by Helena Zhang. SIL Open Font License 1.1, copied verbatim to
`web/fonts/DepartureMono-OFL.txt`.

Upstream: https://departuremono.com

## web/fonts/Basteleur-Bold.woff2

Basteleur, by Keussel, published by Velvetyne Type Foundry. SIL Open Font
License 1.1, copied verbatim to `web/fonts/Basteleur-OFL.txt`. Basteleur carries
a Reserved Font Name, so the family is never renamed or re-released under
another name.

Upstream: https://velvetyne.fr/fonts/basteleur

## Dolmenwood

[Dolmenwood](https://necroticgnome.com/pages/about-dolmenwood) is © [Necrotic
Gnome](https://necroticgnome.com/). No Dolmenwood text, tables, stat blocks, or hex
keys are in this repository. The tool reads a PDF you own, on your own machine,
and writes its index to a local cache that is gitignored and never published.
Kindred names, class names, table headings, and field labels appear in the
source as the search anchors the extractor needs.
